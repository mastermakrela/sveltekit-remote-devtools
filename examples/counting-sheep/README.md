# Counting sheep

The demo app from the [landing page](https://mastermakrela.github.io/sveltekit-remote-devtools/) videos: a small flock you can add, rename, shear and remove, built so it uses every kind of remote function (`query`, `query.batch`, `query.live`, `prerender`, `command`, `form`).

```sh
bun install
bun run dev
```

Open the page and click the `● remote` button in the bottom-right corner. Data lives in memory and resets when the dev server restarts.
